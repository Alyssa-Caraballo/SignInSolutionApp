# Course: CEN 3024C Software Development 1

# This project is a Spring Boot web-based sing in system designed for Valencia College Students. With this structured interface students are able to track their lab sessions by submitting their personal and academic information.
# Some of the concepts or tools used in this assignment were Spring Boot architecture, Spring Data, Object-Oriented Design, and Bean Validation.
# The expected inputs are the students first and last name, email, and course.
# The expected outputs are validation or error feedback if required fields are missing or fulfilled. Also, successful confirmation view.
